## ⚡ Overview

**Haspr** is a community-driven ecosystem compatible with [Passbolt](https://www.passbolt.com), the open-source password manager for teams. It is built for engineers, DevOps teams, and automation workflows that require frictionless security without compromising cryptographic integrity.

While fully maintaining wire-format and server API compatibility, **Haspr** eliminates daily friction points in local dev loops, shell scripts, and CI/CD pipelines.
